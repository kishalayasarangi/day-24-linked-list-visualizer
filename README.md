# Day 24 — Linked List Visualizer

**120 Days of Code** | NIT Rourkela | Mechanical Engineering

## What this is
An interactive linked list visualizer with animated
insert, delete and search operations.

## How to view
Open `index.html` in your browser.

## Features
- Insert at head, tail or any position
- Delete by value or position
- Search with highlight animation
- Visual node and pointer representation
- Operation log
