About Linked Lists

Insert at Head O(1)
Insert at Tail O(n)
Delete by Value O(n)
Search O(n)

Unlike arrays, linked lists don't need contiguous memory. Each node stores data and a pointer to the next node. Great for frequent insertions and deletions.
